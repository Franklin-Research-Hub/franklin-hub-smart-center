Pages use clean addresses (for example `franklinhubsmartcenter.com/about` instead of `about.html`); GitHub Pages serves the matching `.html` file automatically. Each page is self-contained: images, styles, and scripts are built into the HTML file, so there is no build step. The `assets/` folder holds copies of every image (logo, hero artwork, headshot, program illustrations) for reuse and future edits; the pages do not depend on it.

## Custom domain

The site is served from **franklinhubsmartcenter.com** (registered with GoDaddy) through GitHub Pages. The `CNAME` file in this repository holds the domain name; keep it in place.

## Interest form

The form on `join.html` sends submissions to **franklinhubsmartcenter@gmail.com** through [FormSubmit](https://formsubmit.co). The first submission from the live site triggers an **"Activate Form"** email to that address; after it is confirmed, every submission arrives as an email titled *"New Join Our HUB interest form."*

## Updating the site

Replace the changed `.html` files in this folder, then in PowerShell:

```powershell
git add .
git commit -m "Update website"
git push
```

GitHub Pages republishes the site automatically within a minute or two.
