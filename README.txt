Franklin HUB SMART Center — website
===================================

WHAT'S IN THIS FOLDER
---------------------
12 web pages. Each page is self-contained: images, styles and code are built into
the file, so the pages work on their own. Keep them together in one folder.

  index.html                   Home page (hero + Enter site)
  about.html                   About: purpose, mission, vision, pillars, Knowledge Code
  programs.html                Programs & Academies
  research.html                Research directory
  victoria-love-franklin.html  Researcher profile (opens from the Research page)
  system.html                  The System
  network.html                 Professional Network
  mentorship.html              Youth Mentorship
  events.html                  Events
  partnerships.html            Partnerships + Partner Registry
  get-involved.html            Experience, Community, Collaborate
  join.html                    Join Our HUB + interest form

assets/  Every image used on the site as a separate file (logo, hero artwork,
         headshot, program illustrations) plus the original full-size photos.
         The pages do NOT need this folder to work; it is for your records,
         social media, print, or future edits.

PUT THE SITE ONLINE
-------------------
Upload all 12 .html files to your web host (GitHub Pages, Netlify, your domain's
hosting, etc.). Keep the name index.html exactly as is: hosts show it
automatically as your home page.

If an older version of the site is online, delete these old files from it:
  projects.html, researchers.html, site.html

TURN ON THE INTEREST FORM (one time)
------------------------------------
The form on join.html emails submissions to franklinhubsmartcenter@gmail.com
through FormSubmit (https://formsubmit.co), a free service.

  1. After the site is online, open join.html on your live website and submit
     the form once yourself. (It will not send from a file opened on your
     computer.)
  2. FormSubmit emails franklinhubsmartcenter@gmail.com with an "Activate Form"
     button. Click it. Check Spam if you don't see it.
  3. From then on, every submission arrives as an email titled
     "New Join Our HUB interest form". Replying in Gmail replies to the sender.
